# Django Web Application (Production Docker Setup)

Веб-приложение на фреймворке **Django**, полностью подготовленное к контейнеризации и развертыванию на реальном сервере (production-ready архитектура).

## 🛠 Стек технологий
* **Backend:** Python 3.10+, Django
* **Production Web-Server:** Nginx, Gunicorn
* **DevOps & Контейнеризация:** Docker, Docker Compose
* **Пакетный менеджер / Зависимости:** pip (requirements.txt)

## 🚀 Особенности архитектуры
* **Контейнеризация:** Весь проект разбит на изолированные слои. Написан оптимальный `Dockerfile` для сборки Django-приложения.
* **Nginx:** Настроен в качестве Reverse Proxy для раздачи статических файлов (`static/`, `media/`) и обеспечения безопасности.
* **Gunicorn:** Используется в качестве WSGI-сервера для обработки высоконагруженных production-запросов вместо стандартного учебного `runserver`.
* **Окружение:** Конфигурация приложения и секреты вынесены в изолированный файл `.env` (добавлен в `.gitignore`).

## 📦 Локальный запуск
Для сборки и запуска всей инфраструктуры одной командой выполните:
```bash
docker-compose up --build
```
После запуска проект будет доступен по адресу: `http://localhost:8000`
